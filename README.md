# VrQuest

Quest-style VR launcher for a phone in a VR Box headset.

- Split-screen stereo + lens correction, 3DoF head tracking
- Camera passthrough (fills the view), hand tracking (pinch, fist-grab, poke, two-hand scale)
- Floating windows that stay in place; resize, TV size, full-screen (F11 button)
- YouTube / browser, local video player (Browse files...), gallery, 360 photos
- Environments (rain, storm, space, aurora, sunset, cinema)
- Games: Boxing (gloves on your hands), Zombie Shooter (finger-gun), Gorilla Tag, Painting VR, Piano
- 14 environments: rain, storm, space, aurora, sunset, cinema, Paris, beach, ocean, mountains, desert, forest, city, snow
- Settings: performance presets, gaze dot (auto-click optional)

Build: push to GitHub, Actions builds `VrQuest-apk` artifact.
